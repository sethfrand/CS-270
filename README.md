### Intro to Machine Learning ### 

## Course Description ## 

Understand the fundamental models of machine learning, such as neural networks, decision trees, data mining, clustering, 
Bayesian learning, ensembles, reinforcement learning, and deep learning. Work with data and machine learning tools in real world applications.

## Learning Outcomes ##

# Machine Learning Knowledge #
Students will be able to understand and apply the basic theory, models, and concepts of machine learning and be prepared for subsequent machine learning courses.

# Recognize #

Students will be able to recognize when machine learning approaches are applicable.

# Execute #
Students will be able to use machine learning approaches in real world applications.
